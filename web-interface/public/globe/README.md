# Globe imagery

The main app's `GlobeArrival` uses MapLibre GL JS to animate a spherical Earth
into a north-up, zero-pitch aerial view of Zürich. It loads only on the Campus page.
The journey starts automatically, can be skipped or replayed, and immediately
shows Zürich when `prefers-reduced-motion: reduce` is enabled.

## Earth

- Dataset: Sentinel-2 cloudless / EOxCloudless 2016, EOX IT Services GmbH.
- Contains modified Copernicus Sentinel data 2016.
- Live WMTS: `https://tiles.maps.eox.at/wmts/1.0.0/s2cloudless_3857/default/g/{z}/{y}/{x}.jpg`
- Local loading/failure preview `earth-preview.jpg`: unmodified zoom-zero tile,
  downloaded on 2026-10-09 from the endpoint above, with `z=y=x=0`.
- Licence: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), as stated for
  the 2016 dataset on the [EOX pricing page](https://cloudless.eox.at/pricing).
- [Attribution guidance](https://cloudless.eox.at/documentation/license).

The CSS masks, scales and shades the preview into a sphere. The live map shows
the same attribution in its lower right corner. No imagery is generated by AI.

## Zürich

- Dataset: SWISSIMAGE aerial imagery, Swiss Federal Office of Topography.
- Live XYZ: `https://wmts.geo.admin.ch/1.0.0/ch.swisstopo.swissimage/default/current/3857/{z}/{x}/{y}.jpeg`
- Visible attribution: © Data: swisstopo.
- [XYZ service documentation](https://docs.geo.admin.ch/visualize-data/xyz.html).
- [Terms of use](https://www.geo.admin.ch/en/general-terms-of-use-fsdi).

Both public tile services work without API keys. A network connection and WebGL
are required for the detailed animation; if unavailable, the local Earth preview
and the chat/Arena links remain available with a retry action.

`tests/globe_browser.py` checks the compiled worker, automatic flight, skip/replay,
mobile marker placement, reduced motion, navigation, and failure/retry. It uses
the local preview as deterministic tile fixtures; live imagery and visual quality
are checked separately against the real services.
